Use the official release at commit `2f63dae1a01d51453826fe07ef5cf6678e339588`, retaining raw files. Audit template counts, grade/session pairs, student/class counts, missingness and score support before modelling. Reproduce source practice and independent treatment patterns before novel analyses.

The primary outcome is continuous matched independent-item score. Fit practice score by condition, previous GPA and source-design context; report class-clustered uncertainty and condition-specific practice slopes. Design coding and complete-case exclusions will be recorded in the script and results JSON before model execution. Random allocation does not make associations conditional on post-treatment practice success causal.

Primary decision: full-correct practice (D=1) and full-correct independent item (Y=1). Report coverage, independent success, unconfirmed-positive proportion P(Y=0|D=1), burden P(D=1,Y=0), and missed independent success P(D=0,Y=1). These reconstructed decisions are not teacher decisions or validated mastery diagnoses. Primary contrasts are GPT Base minus Control and GPT Tutor minus GPT Base; Holm correction within the declared contrast family. GPT Tutor minus Control is secondary. Confidence intervals resample classes. Prespecified independent-success thresholds are 0.60, 0.70, 0.80 and 0.90. Practice is binary, so these do not change D.

M0: grade/session/problem design context; M1: + practice score; M2: + condition; M3: + score-by-condition; M4: + prior GPA. Transparent linear/logistic models use class-grouped validation, identical folds and evaluation cases for each model. No class or student can occur in both training and test. Training-fold-only transformations/imputation; no outcome-driven feature or threshold selection. Report continuous MAE, RMSE, held-out R-squared and observed/predicted agreement; binary Brier, log loss, AUC, calibration intercept and slope, and calibration curves. Improvements and intervals conditional on held-out predictions are distinguished from full pipeline uncertainty. Calibration shifts and discrimination loss are separate findings.
